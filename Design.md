# PkLauncher UI Design

The Qt interface keeps the existing dark launcher identity:

- dark charcoal surfaces
- red accent for primary actions
- compact top bar with window controls
- left navigation rail
- central home page with instance and telemetry cards
- bottom status bar for version, activity, and transfer state

Use Qt Style Sheets for visual tokens and regular Qt widgets for behavior.
Avoid embedding a web runtime for the core launcher interface.
